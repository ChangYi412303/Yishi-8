# Yishi-8
**為什麼我不承認維基百科的公信力**  ——  影響力與真實性是兩件事

正名註記：2026年11月11日，原「枍奭界」正式正名為「枍奭」。

在網路世界裡，維基百科目前確實具有國際影響力。搜尋引擎常引用它，許多人把它當成快速了解人物或事件的入口，部分人工智慧系統也會從中擷取資料。這一點，我承認。

但我個人——張枍——不承認它具備公信力，也不接納「它記載的一切都是真實」。

影響力與真實性是兩件事。一個平台被很多人使用，不代表它的內容必然正確；一個條目存在，也不代表它經得起事實檢驗。

---

一、我為什麼作這個區分

維基百科的核心設計是「任何人都可以編輯」。這個設計讓知識得以快速累積，也讓錯誤與偏見有機會被寫入。

當涉及選舉、政治人物、商業利益或意識形態爭議時，條目可能在短時間內被修改、美化、刪除負面內容，或加入不實資訊。部分修改會被社群回退，部分則可能短暫存在，甚至被截圖後廣泛傳播。

更關鍵的是：一旦錯誤內容進入公開頁面，後續的搜尋結果、新聞引用，以及依賴公開資料的人工智慧系統，都可能把它當成可用的素材。源頭若有問題，下游的輸出就難以自動分辨真假。

因此，我可以接受它目前有影響力，但我不會把它當成最終的真實依據，更不會用它來定義我自己創作的價值。

---

二、公開紀錄已證明：竄改與操弄不是偶發

這不是抽象推論。多個國家的公開報導、調查與司法判決，都顯示政治性編輯與利益衝突編輯反覆發生。

在台灣，已有法院判決確認：有人在選舉期間竄改候選人維基百科條目，意圖使人不當選，並被判刑。  

在美國，2006年即有大量來自國會的編輯，涉及刪除不利紀錄、美化政治人物。  

在英國，調查發現國會議員或其幕僚從國會內部網路對多位議員條目進行修改。  

在法國，公開統計顯示相當比例的現任議員條目，曾由本人或助理修改。  

在加拿大、巴西等地，選舉期間候選人條目出現明顯的美化與抹黑編輯。  

部分語言版本甚至出現長期的治理俘獲，使特定意識形態得以系統性改寫歷史敘述。

此外，付費公關公司以未揭露方式為客戶美化條目的案例，也多次被調查揭露。

這些案例不代表每一次編輯都是惡意，也不代表所有條目都不可信。它們只證明一件事：開放編輯加上利益動機，足以讓內容在特定時刻偏離事實。

平台有回退機制，不代表錯誤從未被讀者看到；條目最終被修正，不代表中間過程沒有影響。

---

三、我對《枍奭》的選擇

《枍奭》是我自己創造的思想與作品體系。我不需要先取得任何百科平台的認可，才開始保存自己的創作。

我選擇 GitHub，不是因為它完美，而是因為它能讓我持續留下原始文件、版本紀錄與時間脈絡。今天寫了什麼、何時修改、觀點如何演變，都可以被追溯。這比等待一個平台決定「值不值得收錄」更符合我對創作主權的要求。

作品的價值，最終仍要回到作品本身，以及它能否經得起時間、事實與讀者實際使用的檢驗。  

我不把這個檢驗的權力交給維基百科。

---

四、結語

我承認維基百科目前在國際上有影響力。  

我不承認它具備公信力，也不接納它記載的一切都是真實。

這不是情緒，而是對公開紀錄的判斷。

影響力可以存在；真實性必須另作檢驗。  

對我而言，創作紀錄的主權，比平台認可更重要。
